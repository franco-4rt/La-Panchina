# La-Panchina
The problem we are looking to solve with this project is that "La Panchina" doesn't have a website. This problem persists as the owners don't invest in a website. It's an educational project aimed to give experience for every team member and make business easier and more organized, also help the restaurant reach more people. The customers and administration of the restaurant are the target audience of this project.As of today the project has 5 major features. Many individual ones, inside the user and admin frontends of the project. The goal of this project is to help the user gather information while allowing customer-restaurant interactions via online deliveries and table bookings

There is enough work cut out for the 5 people of this team.

Systems we will use and we plan on improving them (we are using: https://stockandsupplyvancouver.com as a reference because "La Panchina" doesn't have a website):

  - role based-authentication and authorization: We don't know if they have a login system, so we plan on implementing it to quicken and ease table bookings.
  - review sytem-website reviews and google reviews: They have a section for user-reviews and media outlets.
  - reservation management system: The reference uses a third-party system but we plan on implementing a system of our own.
  - menu management system: This sytem will only available for the Admin side of the app
  - Notification system: We plan on using e-mail or SMS for notification regarding booking.
